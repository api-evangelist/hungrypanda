# HungryPanda

> HungryPanda (熊猫外卖) is the largest Asian food delivery platform serving overseas Chinese
> communities. Founded in Nottingham, UK in 2017 and headquartered in London, it operates a
> consumer marketplace app, a rider delivery network, the Panda Fresh Asian grocery e-commerce
> platform and the VouchersPanda lifestyle-deals platform across 80+ cities in ten countries:
> the UK, France, Italy, the USA, Canada, Australia, New Zealand, Japan, South Korea and Singapore.

IMPORTANT FOR AGENTS: HungryPanda has NO public API. There is no developer portal, no published
OpenAPI/GraphQL/AsyncAPI specification, no SDK, no sandbox, no self-service sign-up and no
documented rate limits. A real merchant/partner ordering API exists, but access is granted only
through a sales process and its credentials (App Key, Secret Key, ShopID) are issued by
HungryPanda to approved merchants and POS partners. Do not attempt to call it anonymously: every
unauthenticated request returns HTTP 200 with the body {"code":40001}.

## API surface (gated, undocumented)

- Regional API hosts: https://api-{uk,usa,eur,ca,aus,nzd,jp,kr,sg}-f2e.hungrypanda.co
- Regional gateways: https://{uk,usa,fr,ca,aus,nzd,jp,kr,sg}-gateway.hungrypanda.co
- Observed path groups: /api/merchant/*, /api/app/merchant/*, /api/app/user/*, /api/erp/shop/*,
  /api/delivery/app/common/v4/*
- Error envelope: {"code": <int>} returned with HTTP 200 even on failure. Not RFC 9457.
- Capabilities described by integrators: order injection into a merchant POS, order-status
  updates back to HungryPanda, location-scoped menu synchronisation.
